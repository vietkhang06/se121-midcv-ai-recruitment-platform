# System Scope & Boundaries (`docs/final/scope.md`)

## 1. Approved MVP Scope
- **Candidate Journey**: Public job discovery, quick onboarding, profile management, CV builder (with technology, marketing, finance, design templates), PDF export, CV library, JD-aware quick application.
- **HR Recruiter Journey**: Company registration/verification, job posting creation, application list management, AI candidate ranking engine, detailed candidate match inspection, grounded quote evidence display, neutral GitHub assessment display.
- **AI Core Processing**: LLM JD requirement extraction, LLM CV profile parsing, skill normalization, 1536-dim vector embedding generation (Pgvector), 3-tier matching engine, candidate ranking, and GitHub repository activity analysis.

## 2. Explicit Out-of-Scope Features (Locked Boundaries)
As per project directives, the following post-hiring/ATS platform features are strictly **EXCLUDED**:
- Interview Scheduling & Calendar Sync
- Video Interviewing Platform
- Offer Letter Management & Digital Signing
- Payroll & Compensation Management
- Billing, Subscriptions & Payment Gateways
- HR CRM & Employee Lifecycle Management
