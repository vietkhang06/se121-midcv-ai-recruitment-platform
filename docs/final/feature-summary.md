# Feature Summary (`docs/final/feature-summary.md`)

## 1. Candidate Features
1. **First-Visit Onboarding**: Direct selection of Candidate or Recruiter role with immediate job browsing.
2. **Public Job Search & Filters**: Search jobs by keyword, industry, seniority, location, and commitment type.
3. **CV Builder & Industry Recommendation**: Interactive form with real-time preview, template selection (Tech, Marketing, Finance, Design), and PDF export.
4. **CV Library**: Upload, manage, edit, and set active default CV versions.
5. **JD-Aware Quick Apply**: One-click application attaching active CV snapshot version.

## 2. Recruiter & HR Features
1. **Company Profile & Verification**: Unverified companies saved in DRAFT mode; publishing blocked until verified.
2. **Job Posting Management**: Create, edit, save draft, and publish job descriptions.
3. **AI Candidate Ranking Engine**: Ranks applicants based on Required Skill Match, Core Relevance, and GitHub Supporting Score.
4. **Detailed Candidate Match Inspection**: Displays 3-tier scores, matched vs missing skills, exact quote evidence from CV/JD, and neutral GitHub activity assessment.
