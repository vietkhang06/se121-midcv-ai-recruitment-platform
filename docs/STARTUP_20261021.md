# Hướng dẫn khởi động và kiểm chứng — 21/10/2026

## Runtime quan sát được

Máy phát triển tại thời điểm kiểm tra: Java 21.0.11, Node.js 24.15.0, Python 3.11.9. Cấu hình khai báo PostgreSQL 16 + pgvector. Không có xác nhận DB/service đang chạy trong lượt triển khai này.

## Cổng theo cấu hình

- Backend Spring Boot: `PORT_BACKEND` (mặc định 8080).
- Frontend Next.js: `PORT_FRONTEND` (mẫu env 3000); API origin `NEXT_PUBLIC_API_URL` (mặc định local trong frontend env mẫu là `http://localhost:8080`).
- AI worker: `PORT_AI_SERVICE` (mẫu env 8000).
- PostgreSQL mặc định backend URL `localhost:5432`; compose disposable remediation map `127.0.0.1:55432` tới container 5432.
- Ollama mặc định `localhost:11434` nếu bật fallback local.

## Cấu hình và chạy local

1. Tạo `.env` cục bộ từ `.env.example`, thay mọi mật khẩu/secret mặc định. Không commit `.env`. Frontend dùng `frontend/.env.local` dựa trên `frontend/.env.example`.
2. Nếu dùng compose disposable đã chuẩn bị: cấu hình `DATABASE_PASSWORD` trong môi trường; `docker compose -f docker-compose.remediation.yml up -d postgres`. Volume riêng tên `remediation_pgdata`; không dùng lệnh xóa volume. URL backend phải trỏ cổng 55432. Migrations Flyway tự chạy khi backend khởi động; kiểm tra trước nội dung migration và chỉ chạy trên disposable DB.
3. Backend: `cd backend; .\mvnw.cmd spring-boot:run` (hoặc `mvn spring-boot:run` nếu Maven cài global).
4. Frontend: `cd frontend; npm install; npm run dev`.
5. Worker: `cd ai-worker; python -m venv .venv; .\.venv\Scripts\Activate.ps1; pip install -r requirements.txt; uvicorn app.main:app --host 127.0.0.1 --port 8000` (Dockerfile xác nhận module và cổng 8000).
6. Cấu hình provider OAuth theo `OAUTH_GITHUB_SETUP.md`. OAuth secrets chỉ ở backend.

Không migration hoặc reset database hiện hữu trong hướng dẫn này. Migrations V21–V24 là additive nhưng cần review và chạy riêng trên DB disposable trước.
