# E03 — Separate offline and live CI

Status: **PARTIAL** until both workflows run on GitHub for the final pushed SHA.

## Implementation

- Replaced the monolithic workflow with `ci-offline.yml` and `ci-live.yml`.
- Offline PR CI runs backend with pgvector PostgreSQL, deterministic worker tests excluding `live`, and frontend lint/contracts/build without cloud credentials.
- Live CI is manual and bounded. It starts a real pgvector DB, FastAPI worker with mock disabled, Spring backend, standalone Next frontend and Chrome.
- Live CI runs the worker contract, authenticated public GitHub API, U01 real DB + real HTTP acceptance and U02 browser matrix.
- Optional external LLM smoke is called only when explicitly requested and configured; classification distinguishes `LIVE_NOT_REQUESTED`, `LIVE_NOT_CONFIGURED`, pass and fail.
- Every job emits exit codes, classification, sanitized logs, JUnit where available and commit-scoped artifacts.
