# U01 — Persistent account workspace

Status: **PARTIAL**  
Database: disposable `pgvector/pgvector:pg16`, PostgreSQL 16.15; removed after verification.

## Verified

- Flyway applied V1–V34 on a new database and a V27 fixture upgraded to the actual current migration without a stale hard-coded count.
- Account and plan are read from the backend; upgrade request persists but does not change `STANDARD` to `PRO`.
- Preferences persist and reload through HTTP.
- Cover letters support create/list/delete, validation and cross-user denial.
- Saved jobs are unique/owner-bound and profile views require a real application/recruiter event in the real-DB service suite.
- Unauthorized account HTTP returns 401; cross-user letter update returns 404.
- Preferences, cover letter and upgrade request survived a graceful Spring Boot stop/start and fresh login against the same PostgreSQL database.
