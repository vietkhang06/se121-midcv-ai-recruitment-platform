# S02 — Injection and malicious-document defense

Status: **PASS** for offline/local acceptance; no external-provider quality claim.

## Changes and verified controls

- CV system instructions explicitly treat document content as untrusted data; attacker-supplied closing tags are neutralized.
- Malformed LLM output is JSON-string encoded in the bounded repair prompt.
- Generic API failures no longer echo raw exception text. Logs retain stage/category but not raw payload.
- Provider/embedding errors no longer log raw response bodies; credentials, bearer values, emails and phone numbers are redacted.
- Pydantic/schema validation diagnostics are sanitized.
- PDF and DOCX injection payloads remain extracted document text and cannot become prompt structure.
- Existing 10 MB, page, pixel, type/signature, malformed-file, OCR timeout and schema-grounding gates remain enabled.
- GitHub README/content is not fetched by the current GitHub client, so README prompt injection has no ingestion path.
